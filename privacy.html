Privacy Policy

Last updated: 2026-11-03

Kreycin Control ("the app") is a personal tool run by the owner of the Kreycin YouTube channel. It is used only with the operator's own Google accounts and YouTube channels.

Data the app accesses

With the operator's consent through Google OAuth, the app uses the YouTube Data API and YouTube Analytics API to upload videos, set thumbnails, captions and playlists, and read analytics for the operator's own channels.

How data is stored

OAuth tokens and analytics results are stored only on the operator's own computer. The app has no server, does not sell or share data with third parties, and does not use data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
